Crear respaldo

Genera un respaldo local (.bak de SQL Server) y lo descarga al equipo, sin nube externa.

¿Cómo restaurar un respaldo en Azure SQL Database?

El botón “Generar Respaldo Local” crea un archivo JSON con una instantánea de datos (roles, géneros, estados y usuarios, sin contraseñas ni rutas de archivos). No es un respaldo completo de la base de datos ni incluye estructura (tablas, índices, procedimientos).

Procedimiento manual (ejecutable):

  1. Descarga el archivo .backup desde “Ver respaldos”.
  2. Instala Python 3 en el equipo del administrador.
  3. Guarda el siguiente script como restore.py junto al archivo descargado y ejecútalo: python restore.py mindzyx_backup_*.backup > restore.sql
  4. Revisa restore.sql antes de ejecutarlo.
  5. Abre Azure Data Studio o SQL Server Management Studio y conéctate a la base de datos Azure SQL de Mindzyxs.
  6. Ejecuta restore.sql primero en una base de datos de prueba.
  7. Verifica conteos por tabla y relaciones (usuarios, roles, estados, géneros).
  8. Si todo es correcto, ejecuta el mismo script en producción en horario de bajo uso.
import json, sys, glob

def q(v):
    return "NULL" if v is None else chr(39) + str(v).replace(chr(39), chr(39)+chr(39)) + chr(39)

files = glob.glob(sys.argv[1])
if not files:
    raise SystemExit("No se encontro el archivo de respaldo")
d = json.load(open(files[0], encoding="utf-8-sig"))
for r in d["data"]["roles"]:
    print(f"INSERT INTO dbo.roles (id_rol, nombre) VALUES ({r['IdRol']}, {q(r['Nombre'])});")
for g in d["data"]["generos"]:
    print(f"INSERT INTO dbo.generos (id_genero, nombre) VALUES ({g['IdGenero']}, {q(g['Nombre'])});")
for e in d["data"]["estados"]:
    print(f"INSERT INTO dbo.estados (id_estado, nombre) VALUES ({e['IdEstado']}, {q(e['Nombre'])});")
for u in d["data"]["usuarios"]:
    print(f"INSERT INTO dbo.usuarios (id_usuario, id_rol, id_estado_cuenta, id_estado_aprobacion, nombre, apellido, correo, fecha_nacimiento, fecha_registro, id_genero, ultimo_acceso) VALUES ({u['IdUsuario']}, {u['IdRol']}, {u['IdEstadoCuenta']}, {u['IdEstadoAprobacion']}, {q(u['Nombre'])}, {q(u['Apellido'])}, {q(u['Correo'])}, {q(u['FechaNacimiento'])}, {q(u['FechaRegistro'])}, {q(u['IdGenero'])}, {q(u['UltimoAcceso'])});")

Precauciones: evita duplicar registros; realiza la restauración en horario de bajo uso; conserva una copia del archivo original.

Limitaciones: el JSON no incluye contraseñas, rutas de archivos, tablas de auditoría ni esquema. No se puede importar directamente a Azure SQL sin transformación. Mindzyxs no incluye restauración automática; el script anterior es una herramienta externa de apoyo.
